- 每个页面在 `src/views/` 下以 PascalCase 目录组织，主入口统一命名为 `index.vue`，子组件放在同级 `components/` 子目录中。
- API 调用按业务域拆分为 `src/api/*.ts` 单文件模块，统一通过 `src/utils/request/index.ts` 导出的 `request` 实例发起，不直接 import axios。
- 自研组件遵循 `src/xbUi/XbComponentName/index.vue` 结构，类型定义放入同名 `types.ts`，函数式调用（如 Message/Confirm）单独放在 `method.ts`。
- 路由守卫与后置钩子拆分为 `guards/beforeEach.ts` 与 `guards/afterEach.ts` 两个文件，不在 `routes.ts` 内联编写。
- HTTP 响应体统一解包为 `ApiResponse<T>` 后再返回业务数据，所有 `.then(res => res.data.data)` 模式集中在 RequestClient 内部完成。
