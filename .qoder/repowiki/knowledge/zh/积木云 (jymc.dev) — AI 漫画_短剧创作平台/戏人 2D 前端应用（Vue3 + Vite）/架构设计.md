模块采用标准 Vue3 SPA 分层：
- 入口 `src/main.ts` 挂载 Pinia、vue-router 与自研插件 `xbUi`，并通过事件总线注册全局 HTTP 状态码处理。
- 路由层 `src/router/` 使用 `createWebHashHistory`，守卫拆分为 `beforeEach.ts` / `afterEach.ts` 两个独立文件集中维护鉴权与埋点逻辑。
- 业务 API 按领域拆分到 `src/api/*.ts`，统一通过 `src/utils/request/index.ts` 暴露的 `RequestClient` 发起请求；该客户端封装 Axios 实例并内置请求/响应拦截器链（token 注入、白名单校验、错误广播），同时提供 `upload`（FormData 进度回调）和 `ssePost`（XMLHttpRequest 流式解析 OpenAI 风格 SSE）两类扩展方法。
- 状态集中在 `src/stores/`（user、assets、projects、marketplace、siteConfig），配合 `src/config/aiModels.ts`、`assetTypes.ts` 等静态配置。
- 视图以 `src/views/<Page>/index.vue` 为根，子功能下沉到同目录 `components/` 下，布局由 `src/layouts/AppLayout.vue` 承载 TopBar/SideNav/NotificationPanel 等公共区域。
- 自研 UI 库 `src/xbUi/` 以 `index.ts` 作为 Vue Plugin 批量 `app.component` 注册，每个组件独立文件夹含 `index.vue` 与可选 `types.ts`/`method.ts`，并提供 `XbMessage`、`XbConfirm` 等函数式调用接口。
- 构建侧 `vite.config.ts` 配置 `@` 别名、`unplugin-auto-import` 自动导入 vue/vue-router/pinia，开发代理 `/proxy` → 本地 39120 端口，`white.json` 被 watch 忽略避免热重载。
