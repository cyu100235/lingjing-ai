仓库采用前后端分离的双进程架构：`frontend/` 通过 Vite dev server 将 `/proxy/*` 反向代理到 `server/`（Webman + workerman）的 39120 端口，两者通过 RESTful API 契约通信，统一响应体 `{status,data,msg}` 并由前端 RequestClient 自动解包。

- 后端以 Webman 插件体系组织，核心由 `plugin/xbCode` 框架插件承载，业务按领域拆为 `xbMovieApp`（站点/剧集/白名单扫描）、`xbUser`、`xbUpload*`、`xCoupon`、`xbAiModelAgent`（AI 模型管理、媒体生成、计费、TaskServer 后台任务）等插件，每个插件自含 config/app/api/enum 目录。
- 前端通过 `utils/request/index.ts` 单例发起请求，白名单路径由后端 `WhitelistScanner` 动态写入 `utils/request/white.json`，实现前后端鉴权策略同步。
- 枚举类型在 PHP 端以 `xbAiModelAgent/enum/` 定义，前端在 `src/api/modelEnum.ts` 保持对应 TS 类型，形成跨语言枚举契约。
- 后台管理面板由 amis JSON schema 自动生成，控制器只返回 schema 不渲染 HTML，前后端共享同一套路由命名约定 `/app/{pluginName}/api/{ControllerName}/{method}`。
